# Bundled companion assets

`pekka-pal.codex-pet` is a user-provided local pet package bundled with this
build at the user's explicit request. Piora does not claim ownership of the
character artwork. The package remains replaceable from Piora's pet settings.

`azure`, `corgi-scout`, `fox`, `patchi`, `penguin`, `professor-hoot`,
`rabbit`, and `shadow-kit` are OpenPets-original packages redistributed from
the OpenPets v3 catalog under the MIT license in
`third_party/openpets/LICENSE`. Source and snapshot details are recorded in
`third_party/openpets/SOURCE.md`.

`/companion-pets/piora-bot.webp` is an original Piora mascot generated for
this project. It is not derived from a third-party character or logo.
