# 中转站 Markdown 写作设计

## 产品目标

中转站面向随手记录、长文整理和本机资料流转。体验基准是 Typora 的日常写作路径：正文始终可直接输入，格式在当前编辑位置显示 Markdown 语法，离开后恢复排版；复杂对象可以直接操作；文件管理、恢复和导出都在同一工作区完成。

Markdown 文本是唯一正文来源。编辑器不会维护另一份富文本模型，因此切换即时排版、源码和阅读视图时无需重新序列化，已有空格、换行和用户手写语法不会被编辑器自动改写。

## 交互原则

1. **选择文字时保持安静。** 选区不会自动弹出工具条。右键才打开上下文菜单，菜单按实际尺寸限制在窗口内；滚动、缩放、窗口失焦或按 Esc 时关闭。
2. **当前行显示语法。** 即时排版隐藏非当前行的标题、强调等标记。光标进入该行后显示原始标记，便于精确修改。
3. **操作保持上下文。** 即时排版与源码共用同一个 CodeMirror 文档、选区和撤销历史。查找替换不会强制切换视图。
4. **对象就地编辑。** 表格单元格、待办框、图片、块公式和 Mermaid 在正文内显示；进入对象或打开对象菜单时再显示编辑能力。
5. **写入必须可恢复。** 自动保存、版本冲突和本机恢复副本共同保护正文。关闭、删除、阅读和导出前先等待输入法及图片上传完成；保存失败时保留编辑器和恢复副本。

## 编辑能力

### 文本与段落

- 段落和 1–6 级标题。
- 加粗、斜体、删除线、行内代码、高亮、下划线、上标和下标。
- 链接对话框可修改显示文字与地址。
- 无序、有序和任务列表，引用、带语言语法高亮的代码块、数学块、分隔线；代码围栏内的 Markdown 字符始终按代码处理。
- 从网页或文档粘贴富文本时转换为 GFM 标题、列表、表格和链接，并移除脚本及危险链接；纯文本粘贴保持原文。
- 工具栏、键盘快捷键和右键菜单调用同一组纯 Markdown 事务；每次操作进入同一撤销历史。

### 表格

- GFM 表格在即时排版中显示为可直接输入的单元格。
- Tab/Shift+Tab 在单元格间移动，从最后一格按 Tab 自动增加一行。
- 右键可在当前行或列前后插入、删除行列，并设置当前列左对齐、居中或右对齐。
- 光标进入表格源码时显示原始 Markdown，避免视觉组件遮住精确编辑。

### 图片、公式和图表

- 支持文件选择、剪贴板粘贴、正文拖放和多图上传。每个上传先写入唯一占位符，用户可继续输入；完成后只替换对应占位符。
- Markdown 图片和带 `width` 的 HTML 图片都在正文显示。点击图片打开地址、替代文字、标题和像素宽度编辑；设置宽度时使用标准 `<img>`。
- `$$` 数学块使用 KaTeX 即时渲染；围栏语言为 `mermaid` 的代码块异步渲染，语法错误保留可读错误信息。

### 查找与专注写作

- 查找面板支持大小写、整词、正则和替换，保留当前编辑模式。
- 大纲按标题层级展示，支持筛选，跟随光标标记当前位置并可跳转。
- 当前段落模式降低其他行的视觉权重；打字机模式让输入位置保持在视口中部。
- 即时排版采用普通界面字体；源码模式显示行号并使用等宽字体。

## 文档工作区

- 文件夹、文档和图片共用文件树，支持搜索、按名称或最近更新排序、拖放移动和多标签页。
- 标签支持键盘切换和拖动排序；工作区宽高、侧栏宽度、正文字号和固定/自适应栏宽保存在本机。
- 删除进入回收站。回收站可恢复或二次确认后永久删除；恢复嵌套内容时一并恢复其文件夹路径，含内容的文件夹不能被永久删除，图片文件仅在永久删除时从磁盘移除。
- 文档可复制为副本。外部磁盘内容更新时，未修改的打开文档立即同步；有本机修改时保留草稿并走现有冲突处理。

## 导入、导出与打印

- 导入 `.md`、`.markdown`、`.txt`、图片和 ZIP。写入前先检查文件数量、容量、文档和附件并显示确认摘要，取消时不创建任何内容；ZIP 会读取其中的 Markdown，并将相对图片附件写入中转站后重写引用，缺少附件或格式不受支持时明确失败。批量写入中途失败时自动撤销本次已创建的条目，并如实提示无法撤销的异常。
- 导出 Markdown 时，无本机图片直接生成 `.md`；有本机图片生成 ZIP，正文使用可携带的相对路径并对重复附件去重。
- HTML 导出使用 GFM、原始 HTML 白名单和 KaTeX 管线，将本机图片嵌入 data URL；浏览器环境中同时把有效 Mermaid 块转为内嵌 SVG。导出文件可离线阅读。
- PDF 通过专用阅读排版调用系统打印，隐藏工作区控件并展开正文。

## 技术结构

- `components/MarkdownEditor.tsx`：CodeMirror 6 实例、模式区间、装饰器、对象组件、菜单、对话框和输入事件。
- `lib/markdown-editor-commands.ts`：不依赖 DOM 的 Markdown 与表格事务，负责范围、替换文本和新选区。
- `lib/markdown-draft.ts`：自动保存、本机恢复、并发保存串行化和磁盘版本同步。
- `lib/markdown-export.ts`：Markdown/ZIP/HTML 导出及本机图片携带。
- `components/CompanionTransferStation.tsx`：标签、文件树、大纲、回收站、导入导出和阅读视图。

编辑器只在中转站打开时进入客户端包，不依赖 CDN。CodeMirror、KaTeX、Mermaid 和统一 Markdown 处理管线均由锁文件固定版本。

## 验收范围

- 纯函数测试覆盖行内格式、段落、表格行列与对齐、图片 Markdown/HTML 往返。
- 草稿测试覆盖保存中继续输入、失败恢复、空文档、外部更新和恢复存储失败。
- 存储测试覆盖回收站恢复、永久删除、版本冲突、容量限制和旧数据迁移。
- 导出测试覆盖 GFM、数学、图片去重、相对路径、自包含 HTML、附件缺失和类型限制。
- 浏览器测试使用真实 CodeMirror，覆盖选区不弹窗、菜单边界、即时排版/源码历史、查找、代码围栏隔离、表格直接编辑与 Tab 加行、图片尺寸、ZIP 导入预览与回导、大纲和专注布局、窄窗、回收站以及保存失败不丢稿。

## 范围边界

本设计覆盖中转站中的完整日常 Markdown 写作链路。任意本地目录双向同步、Word/EPUB/Pandoc 转换、主题市场和多人协作需要独立的文件权限、转换运行时或协作协议，不属于中转站编辑器本身。
