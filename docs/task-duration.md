# 任务总用时

在聊天输入框上方固定显示一行轻量计时，不随消息滚出视野。运行文案由用户选定为「凝思求解中」，搭配「已用时 2:34」和当前阶段；完成、停止、失败分别显示「已完成」「已停止」「未完成」及总用时。使用主题变量、等宽数字，长阶段文本省略，计时本身不触发屏幕阅读器逐秒播报。

一次任务从服务端开始派发到任务终态，包含模型等待、工具、自动重试、压缩和交互等待，排队时间不计入。运行中的引导消息归属原任务，不替换计时。下一次独立执行重新开始。当前对话保留最近一次计时；这不是整个对话的累计时长，也不是模型推理耗时估算。

`SessionCommandRecord.taskTiming` 随已有命令日志持久保存，通过命令 SSE 与 submissions 的独立 `taskTiming` 字段恢复。历史普通任务的完成事件不会因此重新触发。旧记录无精确时间时不补造；进程异常中断没有可靠结束时间时显示「用时未记录」。后台页根据时间戳重算，停止后保持最终数值。

验证：计时纯函数、路由派发/队列/日志重载、submissions 恢复，以及真实 TaskDuration 组件的浏览器交互。浏览器夹具用按钮模拟任务生命周期，用本地存储模拟重载数据，主题使用与应用一致的变量；截图不代表完整桌面端或真实模型任务验收。

设计概念图由内置 imagegen 生成，提示词要点：Piora 中性灰白界面、蓝色强调，输入框上方轻量单行计时，运行/完成/停止三态及深色示例，阶段切换不清零、刷新恢复、结束保留。概念图早于最终文案选择；以实际组件「凝思求解中」为准。概念图与组件截图保存于 `.verification/task-duration/`。
