# Open-source UI references

Piora's 2026-08 visual refresh is an original implementation informed by two permissively licensed projects:

- [Lobe UI](https://github.com/lobehub/lobe-ui) — compact AI-product surfaces, consistent spacing, and restrained motion.
- [OpenHands](https://github.com/OpenHands/OpenHands) — task-first information hierarchy and clear runtime state presentation.
- [Playwright](https://github.com/microsoft/playwright) — the browser automation runtime used by Piora's private background browser tool.

No theme CSS or branded assets are copied. The shared principles are expressed through Piora's own color tokens, ambient layers, elevation scale, focus states, message rhythm, and reduced-motion behavior. Projects with source-available branding or derivative-use restrictions were intentionally excluded as implementation sources.
