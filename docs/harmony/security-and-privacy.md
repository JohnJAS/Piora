# 授权、数据与隐私

普通会话仍保留 Pi 编码工具、Shell 和扩展；设备结构化工具的策略不是本机沙箱。屏幕文字、日志、应用名称与视觉内容都是不可信输入，不应成为模型指令。需要隔离执行时使用独立受控测试主机。

Agent 的普通控制授权绑定当前任务/lease/设备 epoch 与具体应用。授权范围包含该应用内的提交和发送等可能有外部影响的操作，不能靠按钮名称推断安全。换应用需要新授权；安装、卸载、清数据、录屏、系统按键和校准使用对应单次审批。授权令牌不返回模型；审批过期、换参数、换制品或撤销租约均失效。

HAP 计算 SHA-256 并复制到私有不可变制品区；同一路径换字节不会复用批准。投屏服务来源和许可保留在 third_party，不在被动预览中安装。投屏始终不自动解锁。

支持包默认只含脱敏设备/owner标识、版本、状态和队列，不含原始日志、音频、聊天和截图。包含 UI 文本和截图需要分别勾选；文件保存在本机，最多保留最近 10 个，单包 8 MiB。分享前检查内容。

媒体、校准、场景输入和音频资产存于当前品牌的数据根，不与另一品牌混用；跨品牌只有物理设备锁共享，以防同时控制同一手机。用户选择的截图和录屏目录不进行无差别清理。清理仅操作工具自己创建且可核对归属的文件与转发。

导入的 WAV/HAP 私有副本最多各 500 个、1 GiB；30 天未使用的生成副本在下次导入时过期清理，原始用户文件不受影响。执行记录最多 500 条，工作台可导出结果、删除记录及其私有输入。录屏只保存当前订阅的视频流，单次最多两分钟、256 MiB，不切换系统全局录屏服务。崩溃遗留的控制记录显示恢复中；人工检查释放后方可确认恢复。

视频转发按精确本地端口写入所有权日志。正常关闭只移除本次连接的端口；清理失败会报告 uncertain。崩溃后的端口记录仅供 doctor 展示，不自动删除可能被其他进程复用的端口。开发验证报告可能包含本应用日志，保存在本地私有目录，保留最近 20 份，按选中的工程读取。
