# Piora × Codex 体验对齐方案

基线日期：2026-08-06

目标不是逐像素复制 Codex，而是让高频操作的入口、反馈、键盘路径和稳定性达到同一预期：用户不需要猜功能在哪里，也不会因为悬停、流式输出或面板切换产生布局跳动。

## 已启动并落地：第一阶段

### 聊天滚动

- “滚动到最新消息”只依据真实消息内容判断，忽略流式输出时用于稳定视口的临时尾部占位。
- 内容尚未超过当前消息视口时不显示；长会话离开底部后才显示，点击后回到底部并消失。
- 保留流式输出时的视口稳定，不让新增消息把用户正在阅读的位置抢走。

验收：短回复生成中/完成后按钮均不出现；长会话向上滚动后出现；点击后消失。

### 左侧文件浏览器

- 常驻“筛选文件”输入框，`Ctrl/Cmd + P` 直接聚焦，支持清空、加载态、空结果和键盘选择。
- 文件/目录采用紧凑 24px 行高、稳定的悬停操作区、选中态和 Git 状态标记。
- 右键菜单对齐 Codex：在系统文件浏览器中显示、打开方式、在 Piora 中打开/展开、复制路径、添加到聊天。
- 打开的文件在树和筛选结果中同步高亮，并自动展开祖先目录。
- 左侧底部增加固定设置入口，让浏览器版和桌面版都能进入模型、技能、外观和宠物设置。
- 文件标签页增加选中语义与方向键、Home/End、Delete 关闭等键盘操作。

验收：悬停前后行位置与尺寸不变；筛选结果可打开文件；右键菜单不会溢出视口；Web 模式禁用系统专属动作，Electron 模式调用经过路径校验的系统打开能力。

### Codex 风格项目栏

- 顶部采用品牌区、搜索/设置快捷入口和紧凑主导航；项目、固定项目、任务列表和账户区建立与 Codex 一致的信息层级。
- 项目行提供固定宽度的悬停操作区，任务行保持单行紧凑布局；操作按钮显隐不参与排版，避免鼠标经过时横向或纵向抖动。
- 项目菜单展示真实任务数、运行数、Git 远端、工作区路径和当前分支，支持固定项目、重命名项目和创建新任务。
- 固定状态和项目别名保存在本地；别名恢复为目录默认名时自动清理覆盖值。
- 仅展示已经接通的真实能力；拉取请求、站点和计划任务等尚未接入的 Codex 全局入口列入后续阶段，不放置无效按钮。

验收：项目行与任务行悬停前后位置和尺寸不变；固定/取消固定、重命名/恢复名称、项目菜单和新任务入口均可操作；项目元数据由受限的本地 API 返回。

### Codex 宠物兼容

- 支持从本机 Codex 目录发现并导入宠物。
- 支持上传 ZIP；兼容 `pet.json` 和旧版 `avatar.json`，支持根目录或单层包装目录中的 PNG/WebP 精灵图。
- ZIP 在服务端进行大小、条目数、路径穿越、清单、图片格式、尺寸和图集几何校验，并原子安装；不执行宠物包里的脚本，也不访问远程资源。
- 宠物设置页和宠物面板内均提供使用说明，明确状态、待办、快捷话术、浏览器模式和独立桌宠模式的用法。

验收：有效 ZIP 可安装并自动选中；缺清单/精灵图、危险路径和超限 ZIP 被拒绝；导入后可显示宠物并展开帮助。

### 设置页导航

- 设置不再通过覆盖整个窗口的模态框打开，而是在主应用框架的内容区显示独立页面。
- 左侧项目栏与顶栏保持可见；聊天组件保持挂载，右侧文件面板仅暂时折叠，关闭设置后恢复原任务和文件状态。
- 设置页使用普通页面区域语义，移除 `createPortal`、`aria-modal`、全屏 fixed 遮罩和背景模糊。

验收：Web 与最终便携 EXE 中设置页均位于主内容区，侧栏可继续导航；关闭设置后主界面恢复，控制台无错误。

## 第二阶段：核心工作流对齐（P1）

1. 统一命令面板
   - 将文件、设置、会话、模型和常用操作纳入同一个 `Ctrl/Cmd + K` 面板。
   - 支持模糊搜索、最近使用、分类、禁用原因和键盘全流程。

2. 文件浏览器深度键盘体验
   - 完整 roving tabindex、首字母跳转、多选、Shift 范围选择。
   - 文件夹内新建文件/目录、重命名、删除前确认和可恢复操作。
   - 大目录虚拟化，并把 Git 变更与普通目录树统一为可切换视图。

3. 会话与任务导航
   - 会话列表搜索、固定、归档、未读/运行/需确认状态统一。
   - 最近任务与当前项目的层级、快捷入口和上下文菜单对齐 Codex。
   - 接入拉取请求、站点和计划任务后，再补齐对应的全局导航入口、计数与状态反馈。

4. 面板与标签状态
   - 已完成：标签拖拽排序、关闭其他/右侧标签、重开已关闭文件。
   - 已完成：记忆侧边栏宽度、文件面板宽度、展开目录和上次活动标签。

## 第三阶段：完成度与性能（P2）

- 工作区全文搜索：文件名与正文两种模式、忽略规则、结果预览和跳转行号。
- Diff/审阅工作流：按文件导航、逐块接受/撤销、评论与问题列表。
- 大会话和大仓库性能：消息与目录虚拟化、增量索引、可取消请求和清晰的慢操作反馈。
- 桌面原生细节：系统右键菜单、拖入文件、任务栏/通知、窗口恢复和多显示器桌宠位置。
- 无障碍和视觉基线：焦点环、对比度、减少动画、200% 缩放、窄窗口和中英文截图回归。

## 回归门槛

每批对齐改动至少通过：

- Web 与 Electron TypeScript 检查；
- ESLint 与相关 Node 测试；
- 本地真实界面操作测试，覆盖鼠标、键盘和错误态；
- 无新增浏览器控制台错误；
- 开发服务运行期间不运行 `next build`；桌面发布验收前先停止开发服务，再构建、打包并操作实际 EXE。
- 最终便携 EXE 通过包内容校验、隔离用户目录启动冒烟，并由桌面控制实际验证悬停、滚动、右键菜单和设置页。
