# Piora Stage 4 · Batch 4 验收记录

日期：2026-08-09

## 本批范围

- 左侧栏新增可折叠的“活动”区域，用于快速查看和切换跨项目任务。
- 活动排序统一为：运行中、有新结果、当前任务、最近更新。
- 活动行复用全局任务状态模型和状态指示器，不单独定义颜色或状态判断。
- 归档任务不进入活动列表；任务搜索期间隐藏活动区，让搜索结果保持聚焦。
- 无运行中或未读任务时默认折叠；出现新的活动时自动展开。
- 首屏最多渲染 4 个任务，其余任务通过数量提示留在“项目”列表中，避免挤占侧栏空间。
- 支持键盘展开、收起、选择任务，并提供列表、当前项和相对时间语义。

## 性能与实现约束

- 排序和截断逻辑位于 `lib/task-activity.ts`，作为纯函数独立测试。
- 500 个任务的活动排序性能预算为 50ms，开发机实测低于 1ms。
- 活动行固定状态图标槽位，状态变化不会导致标题横向跳动。
- React 状态仅保留展开状态；活动内容和排序均由现有数据派生。
