### 第二轮已通过的验证

- **38/38 个仓库用例通过**，使用 Node 22.19.0，回环地址直连。其中 35 个服务端、运行时及 SDK 用例，3 个 Edge 浏览器用例，跳过和取消均为 0。工作区 TypeScript 检查及子代理定向 ESLint 通过。
- R1–R4、R6 的原例分别确认旧设置可读、只改说明保留工具约束、单个坏文件不阻止启动、默认无历史 token 上限，以及 `@team`、`001` 能安全往返。
- R5、R7、R8 的原例确认 12,000 字符可从详情恢复、其他项目的旧名模型偏好仍在，以及旧名称空闲时改名后能续跑。N1、N3、N5–N7 覆盖这些修复尚未处理的情形。
- R9–R11 的原例确认启动前拒绝显示原因、普通并行工具按各自 ID 保留活动，以及详情打开第 21 项时选择器仍指向该任务。真实 SDK 的本地 HTTP 用例还能读回本次随机生成的历史标记，兄弟任务读取相同标记时得到缺失结果。
- 上述九项来自额外的隔离复现，未计入 38 项。浏览器复制使用剪贴板替身，SDK 模型请求抵达本地 HTTP 夹具。Electron 开发桌面、真实服务商和 Windows 安装版尚未在此工作区版本上验收。

### 执行顺序与复测入口

先跑 T01–T04、T07、T11 的数据与兼容测试，再接真实 SDK、浏览器以及 Windows 桌面。第二轮应优先把 N1、N2 加入 SDK 与运行时测试，再按表中断言补充 N3–N9。验收一次配置修改时，可把表单提交、重启后读回的文件、子模型真正收到的角色、工具与模型并排核对。

在仓库根目录使用 `.nvmrc` 指定的 Node 22.19.0。下列 PowerShell 命令执行现有七个专题测试文件。

```powershell
node --test --test-concurrency=1 `
  lib/subagents/subagent-refactor.test.mjs lib/subagent.test.mjs `
  lib/subagent-sdk-http.test.mjs lib/subagent-observation.test.mjs `
  lib/subagent-catalog.browser.test.mjs components/SubagentSettings.browser.test.mjs `
  components/subagents/SubagentUi.browser.test.mjs
```

在包含待验代码的专用 worktree 中执行已有 Electron 场景。

```powershell
node scripts/run-desktop-e2e.mjs --scenario subagents --timeout-ms 1200000 --step-timeout-ms 180000
```

真实服务商场景使用 `subagents-real`，安装版本通过 `--executable` 指定。模型、凭据来源和报告目录见[桌面验收说明](../desktop-automated-testing.md)。分别记录开发版或安装版、脚本模型或真实服务商、失败步骤和重跑结果。
