# 工作区文件与内置浏览器问题验证

日期：2026-11-17。范围：#415、#423、#437、#441、#443。按用户要求在 `main` 上提交并直接推送。原 #443 草稿 PR #456 已关闭。

## 实现

- #415：仅对确认的文件 404 按文件名搜索当前工作区，直接遍历实际文件而非依赖 Git 忽略规则；唯一且未截断的结果自动打开，多个结果由用户选择并保留行列定位。搜索沿用文件允许根和真实路径校验，限制数量与深度，不把权限/读取失败误判为文件不存在。缺失界面提供重搜和复制路径；正常会话提示词要求模型提供完整的工作区相对路径。切到其它文件或聊天时取消未完成的自动定位，避免迟到结果抢走焦点。
- #423：浏览器显式设置默认字号、等宽字号、最小字号、UTF-8 与系统等宽字体。新增页面缩放按钮、百分比和 Ctrl/Cmd 加减号/0 快捷键，按 HTTP(S) origin 持久化，支持导航和重启后恢复。站点自定义 CSS 仍受尊重。
- #437：面板拖拽开始立即隐藏原生网页，松开、取消或卸载后重新按可见区域测量。DOM 范围裁剪到面板和窗口，主进程将 CSS 像素按主窗口缩放转换成原生视图坐标，并再次裁剪到内容区。
- #441：全局设置新增“浏览器 → 下载位置”，支持输入/浏览目录、系统默认目录和每次询问。配置存入桌面 profile 的 browser-preferences.json，保存时校验目录并立即更新会话，失败回退到原配置。固定目录下载为新下载选择安全且不冲突的文件名；已经开始的下载使用原先目标。
- #443：在之前菜单上补齐含行号的路径复制、不含行号的文件路径复制及“在 Piora 中打开”；原生资源管理器始终只接收文件系统路径。菜单字号改为全局字体变量，修复 PR #456 CI 的字体一致性检查失败。
