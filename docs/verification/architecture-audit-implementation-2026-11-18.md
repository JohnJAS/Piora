# 全仓架构审计优化验收

基线为 `cf0a9e9a492ddc5451afe64efb95689cc581794b`。实现与测试在独立工作树完成，原工作区已有修改保留在原处。

## 落地

| 范围 | 实现 |
| --- | --- |
| 聊天读取 | 最近 40 轮优先返回，设置体积和行数预算，过大轮次提供预览和原文入口。翻页绑定会话分支，搜索结果可直接定位。统计、长系统提示词、媒体与完整历史按需读取。 |
| 会话索引 | 后台线程维护 JSONL 字节偏移、分支、压缩位置、回执和统计。索引可重建，识别同文件改写、截断和原子替换。外部增长时校验原有字节，验证通过后只解析新增记录。 |
| 命令流水 | 冷读按块异步建索引。按会话、命令 ID、幂等键和事件游标查询，活动命令与近期操作有独立范围。保留原稿、失败与取消状态，核对持久化记录后才确认回执。 |
| 目录与文件 | 侧栏分页使用目录版本，单会话调用读取短元数据。仓库文件排序与搜索有独立 worker、有界缓存和后台刷新。保留原有 Git 忽略规则与路径校验。 |
| 流式交互 | 已完成轮次的行索引在流更新时复用。SSE 对慢连接限制发送队列，重新连接后重放当前状态与待处理审批。停止与完成轮询可只读取运行标志和时钟。 |
| Git 与使用量 | Git 状态从同一次 porcelain 输出读取文件及分支跟踪，独立差异统计并行读取。个人用量在扫描时累加，并发重算合并。组织补账由后台任务处理。 |
| 桌面 | 将开屏交接移到独立协调器。认证服务就绪即释放动画，电影由本地文件加载。记录开屏可见、服务就绪和输入区可交互时间。 |
| 测试与清理 | 主应用测试递归发现，CI 检查测试唯一归属并运行规模基准。用真实 HTTP 处理器、Electron 和浏览器夹具覆盖关键交互。退役无生产入口的视图和旧辅助代码，兼容入口保留。 |

## 验证范围

- 测试发现归属检查和 17 项性能预算通过。`npm run perf:read-models` 校验 1k / 10k / 30k 首包体积、内容末尾、ETag、回执以及重复目录解析。CI 的规模门禁检查结构指标，计时留作趋势比较。
- 根应用及桌面类型检查、改动范围 ESLint、`git diff --check` 通过。此前漏发现的八个测试文件与归属测试一起直跑，共 53 个用例通过。
- 定向测试验证压缩、分支游标、外部日志改写、冷读并发合并、断裂日志、原稿与取消、慢连接、统计、Git 跟踪、主帧开屏交接。浏览器夹具核对 60 次流更新时输入区和旧 Markdown 的重渲染次数均为 0。
- Electron 45.3.1 开发桌面验证 120 轮聊天，首包 80 条、12,608 B，首次绘制无加载闪烁。分页保持原位置，旧回复可搜索定位并返回最新，同一 profile 重启后可重新打开聊天。原生开屏用例覆盖服务就绪释放仍在播放的动画、旧导航阻断及窗口退出。
- 在桌面场景中，开屏可见、本地服务就绪、输入区可交互的首启样本依次约为 2.2 s、20.2 s、27.7 s，同一 profile 重启约为 3.9 s、25.3 s、26.6 s。样本含开发服务编译与同期测试负载，用于核对阶段记录。
- 全量远端 CI、发布安装包、真实模型和 Harmony 真机未在本轮执行。历史兼容详情和旧格式迁移仍会读取完整上下文。目录刷新需要枚举文件和检查版本。历史和命令冷索引仍需读完已有日志，目的是把开销移出关键渲染路径并缩小后续查询范围。
