## 本批范围

- 在“设置 → 通用”内新增设置导入与导出，操作全程不跳出设置页面。
- 导出文件使用带版本号的 JSON 格式，只包含可迁移的界面偏好。
- 导入文件在写入前进行文件大小、产品标识、版本、字段白名单与字段值校验。
- 导入后先显示“当前值 / 导入值”差异预览，用户确认后才写入。
- 应用设置并刷新后，自动重新打开“设置 → 通用”，保持设置流程闭环。
- 文件选择器、状态、错误和差异表格具备键盘及屏幕阅读器语义。

## 安全边界

导出白名单仅包括：

- 主题
- 内置背景或无背景设置
- 字体与字号
- 界面语言
- 完成通知开关
- 全局快捷键开关

明确不导出：API Key、OAuth 凭据、模型配置、技能、插件、项目、会话、聊天记录和自定义背景图片数据。导入不会清空或覆盖白名单以外的浏览器存储。
