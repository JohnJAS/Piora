# Piora 阶段 4 第一批验收记录（2026-08-09）

## 本批范围

- 性能基线：新增 `npm run perf:check`，覆盖 500 个任务过滤、5000 文件索引搜索、2000 项会话窗口计算和 5000 文件目录首屏边界。
- 大目录：目录首次最多渲染 200 个直接子项，接近末尾时按 200 项渐进加载；保留“加载更多”键盘入口，并通过 `aria-posinset` / `aria-setsize` 暴露完整集合语义。
- 大会话：历史消息、工具结果映射和锚点索引只在消息集合变化时重算，不再随每个流式 token 重建；长消息行启用浏览器渲染包含。
- 无障碍：新增跳到主内容链接；审批改为 `alertdialog`，加入焦点陷阱并默认聚焦安全的“拒绝”操作；全局尊重减少动画偏好。
- 多显示器：主窗口和桌宠窗口会监听显示器添加、移除和 DPI/工作区变化，并把不可见窗口回收到当前可见工作区。
