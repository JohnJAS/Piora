# Piora 侧边栏现有行为回归清单

> T-09 是纯重构。本清单记录拆分前的可观察行为；每次搬迁组件后须逐项核对，不得借重构改变功能或交互。

## 应用与主导航

- [ ] 1. 顶部显示紧凑的 Piora 品牌行。
- [ ] 2. 应用菜单按钮可打开桌面端菜单。
- [ ] 3. Projects 导航始终可见并能回到项目列表。
- [ ] 4. Global Skills 入口可打开技能设置。
- [ ] 5. 设置入口使用齿轮图标并打开统一设置页。
- [ ] 6. 浏览器入口保持现有可见性与点击行为。
- [ ] 7. 桌宠入口保持现有可见性与点击行为。

## 项目列表

- [ ] 8. 有会话的项目按最近活动分组显示。
- [ ] 9. 手动添加但尚无会话的项目仍保留在列表中。
- [ ] 10. 项目路径改名或失效后仍可从列表移除。
- [ ] 11. 同一 Git 仓库的 worktree 归入主项目。
- [ ] 12. 当前项目拥有明确选中态。
- [ ] 13. 点击当前项目可折叠或展开任务列表。
- [ ] 14. 点击其他项目会切换 cwd，并按现有规则恢复任务。
- [ ] 15. 项目折叠状态跨刷新保留。
- [ ] 16. 项目置顶状态跨刷新保留。
- [ ] 17. 置顶项目显示于置顶区域，取消置顶后回到普通排序。
- [ ] 18. 项目别名可编辑并跨刷新保留。
- [ ] 19. 项目菜单可新建任务、重命名、置顶/取消置顶、移除。
- [ ] 20. 项目菜单在点击外部或按 Escape 后关闭。
- [ ] 21. 项目元数据展示任务数量与最近活动摘要。
- [ ] 22. 添加项目按钮打开既有目录选择器。
- [ ] 23. 默认目录入口可创建并选择默认 cwd。
- [ ] 24. 自定义目录须经 `/api/cwd/validate` 校验后加入。

## Worktree 与文件树

- [ ] 25. 顶级 Git 项目显示 worktree 切换器。
- [ ] 26. 非仓库或仓库子目录不错误显示 worktree 切换器。
- [ ] 27. 切换 worktree 后 cwd、项目根与任务列表同步更新。
- [ ] 28. 创建与移除 worktree 保持现有确认及脏目录保护。
- [ ] 29. 文件树仍可展开、刷新并打开文件标签。
- [ ] 30. 文件搜索焦点命令仍聚焦现有文件搜索框。
- [ ] 31. 文件或目录 @ 提及仍传给输入框。
- [ ] 32. 文件树与 Git Changes 在本阶段不删除、不迁出侧边栏。

## 任务树与任务行

- [ ] 33. 项目内任务保持既有分组与排序。
- [ ] 34. 默认只显示规定数量的根任务，并可显示更多/收起。
- [ ] 35. 运行中或未读任务即使超出默认数量也保持可见。
- [ ] 36. Fork 子任务按 parentSession 树形缩进显示。
- [ ] 37. Fork 展开/折叠按钮保持状态与 `aria-expanded`。
- [ ] 38. 点击任务立即切换，不因另一个任务运行而弹确认框。
- [ ] 39. 当前任务的未读状态在查看后清除。
- [ ] 40. 运行、等待审批、失败、未读状态使用共享状态映射。
- [ ] 41. worktree 任务在无优先状态时显示分支标记。
- [ ] 42. 行标题取会话名、首条消息、会话 id 的既有回退顺序。
- [ ] 43. 标题溢出时截断，原文可通过普通 title 悬浮查看。
- [ ] 44. 悬浮操作区绝对定位，不改变行高或挤压标题。
- [ ] 45. 重命名按钮进入行内编辑，Enter 提交、Escape 取消、失焦提交。
- [ ] 46. 删除按钮始终先进入行内确认，不支持 Shift 绕过。
- [ ] 47. 删除成功后显示可撤销提示，撤销调用 restore API。
- [ ] 48. 删除当前任务后选中态按现有逻辑回退。
- [ ] 49. 列表刷新不丢失当前任务与滚动上下文。

## 运行态、持久化与可访问性

- [ ] 50. 运行任务仅在页面可见时轮询，后台暂停。
- [ ] 51. 页面恢复可见后立即重新同步运行状态。
- [ ] 52. localStorage 异常或隐私模式下侧边栏仍可使用。
- [ ] 53. 按钮均保留 title/aria-label，展开控件保留 aria-expanded。
- [ ] 54. 小窗口下侧边栏不产生横向溢出。
- [ ] 55. 中英文环境下现有文案与操作均可用。

## 每次拆分后的固定检查

- [ ] `node_modules/.bin/tsc --noEmit`
- [ ] `npm run lint`
- [ ] `npm test`
- [ ] `SessionSidebar.test.mjs` 与 `AppShellProjectSwitch.test.mjs`
- [ ] 浏览器手动检查：项目切换、任务切换、重命名、删除与撤销、折叠、设置入口
