# Git 工具与工作树入口重构方案

## 目标与范围

将左侧项目内的工作树管理移到主对话右上角，参考用户提供的 ZCode 卡片：紧凑标题栏、改动摘要、当前分支、提交入口。保留 Piora 的主题、已有 Git 接口与提交流程，项目侧栏继续负责项目和对话导航。

采用点击打开的非模态浮层，不常驻占用聊天宽度。入口展示「Git 工具」与增删行数，窄窗口只保留图标和数字。点击外部、再次点击入口或 Escape 关闭；Tab 在浮层内循环，关闭后回到触发按钮。

## 能力取舍

| 参考界面 | Piora 落地 |
| --- | --- |
| 更改与增删统计 | 复用 Git 状态摘要及现有差异面板；继续采用 tracked diff 口径，不把未跟踪文件全文算成新增行 |
| 分支下拉 | 展示当前 checkout 分支；展开同仓库工作树列表，显示分支、主工作区标记及路径 |
| 提交或推送 | 进入已有 ReviewPanel，打开提交区域；保留暂存、提交说明、身份检查及推送预览流程，不一键自动提交 |
| 展开按钮 | 打开完整更改面板 |
| 更多菜单 | 不创建空菜单，改为刷新与关闭 |
| 进程 0/4 | 不搬入；Piora 没有该配额/状态含义的对应接口 |
| 智能体 | 不搬入；不把房间成员等其他概念伪装为相同功能 |

## 浮层信息结构

1. 标题「Git 工具」，右侧刷新、展开、关闭。
2. 「更改」和绿色新增/红色删除数字；点击进入完整更改面板。
3. 当前分支；无附着分支时显示「分离的 HEAD」，点击展开工作树区域。
4. 「提交或推送」，进入既有操作界面。
5. 展开的工作树区域：条目数、八个及以上条目时的搜索、可滚动列表、新建表单、必要的移除确认。
6. 底部当前工作目录，长路径省略但可通过 title 查看完整路径。

不额外展示未经接口支持的任务进度、智能体数量或后台进程。非 Git 目录不显示该入口。请求失败显示错误并允许刷新，不沿用另一个项目的数据。

## 工作树交互

- 选中当前工作树仅关闭浮层，不重建对话。
- 选择其他工作树使用现有新对话流程，在该目录创建待发送的新对话。原对话、历史和正在运行的任务不迁移、不终止。列表明确说明这一行为。
- 切换后将目录保存在页面地址，刷新可恢复；在导航前缓存工作树的主项目归属，避免尚无会话的新工作树被误判为独立项目。
- 新建：填写分支名称，POST `/api/worktrees`；已有分支由现有后端复用，成功后在新目录打开新对话。失败保留输入与错误；提交期间阻止重复请求。
- 移除：主工作区不提供移除按钮，当前 checkout 的移除按钮禁用并说明需先离开。其他 checkout 先确认移除目录且保留分支，随后使用现有 DELETE 接口；若返回 409 dirty，显示未提交/未跟踪文件会丢失的说明，仅在用户点击「丢弃更改并移除」后传 `force: true`。
- 工作树切换属于目录/对话导航，不等同于对当前 checkout 执行 `git checkout`。已有分支切换功能继续留在完整更改面板。

## 实现边界

- `GitToolsPopover` 位于 AppShell 的 conversation toolbar，portal 到 body 避免聊天滚动容器裁剪；按当前 cwd 重挂载，旧请求与未完成操作不能覆盖另一个项目的界面。
- Git 摘要复用 AppShell 现有刷新与缓存，不重复创建轮询。工作树列表仅在浮层打开时读取，显式刷新或增删后更新。
- `useWorktrees` 同时向侧栏提供只读项目归属信息，因此没有会话的 worktree 仍归属主项目。删除旧 WorktreeSection、旧交互 hook，以及项目菜单里的旧管理入口。
- 提交入口使用带 cwd 的请求属性传递到 ReviewPanel，避免动态加载时丢失一次性的窗口事件。
- 中文/英文文案齐全；浅色/深色使用主题变量。键盘焦点、长分支、窄窗口与视口高度变化纳入验证。

## 验收

- 回归项目/会话切换，确认旧对话不被重置；工作树区域从左侧完全移除。
- 浏览器夹具覆盖多项目隔离、单工作树入口、创建、切换、当前目录不可移除、dirty 确认、返回主工作区与非 Git 情况。
- 完整 Next 应用通过 `node scripts/verify-git-tools.mjs` 验证：隔离配置与测试 Git 仓库，不连接真实模型；通过实际 UI 打开浮层、进入提交、创建工作树和刷新恢复，保存完整应用截图。
- 完整应用截图中的对话为预置验证数据。它们不是示意 HTML，但也不代表真实模型执行或 Electron 发布包验收。结果与未覆盖项记录在 `.verification/git-tools-*/report.json`。
