# Piora 日本語案内

Piora is an independent desktop GUI for the Pi coding agent. The current canonical project
documentation is the Chinese-first [README.md](README.md). An up-to-date Japanese translation is
not available yet.

Piora evolved from `agegr/pi-web`, but it has its own repository and release process. Do not use
the former `@agegr/pi-web` installation commands for Piora.
