# 晴汐的桌边短步

放下杯子后，晴汐先望向要走的方向，双手轻叠在围裙腰线上。她保持四分之三侧身，小步移开 242 个画面像素。最后一只脚落稳后，指尖分开，双手才落到裙侧。返程略微错开两只袖子的摆动，到桌边后重新拢起双手。去程 156 帧，返程 166 帧，每秒 60 帧。

双手的位置参考成都职业技术学院《职业礼仪》示范的身前叠手站姿。将这个手型延续到行走中属于晴汐的动作设计。脚步和肩部姿态参考日本服务礼仪协会的接客步态说明。脚掌落地后固定在露台坐标，身体重心经过支撑腿时，膝盖在保持腿长的情况下弯曲。[身前叠手示范](https://www.cdp.edu.cn/__local/E/BE/B0/09D2517B1B1250971E6C49CE9A5_182DFE2F_29E30F.pdf) · [接客步态说明](https://www.j-manner.com/service/sp/cat41/post-4.html)

`carriage.webp` 由左至右保存两张 384 × 512 的关键画稿，分别是双手轻叠于腰前和松手下落。用 `../center/turn.webp` 第一行第二格的三分之四侧面图作为编辑目标，以 `../cels.webp` 的第 0 个站姿作为手型参考，借助 ImageGen 补画被衣袖挡住的衣料与头发、叠手和松手动作，再将变化的手臂和腰部对齐拼回原画。脸、裙摆、鲸尾等部分沿用原图。行走中双手与袖口作为整体随躯干轻微移动，避免两只手在指尖处分离。

`carriage-release.webp` 是 7 行 × 7 列的局部图集，每格 165 × 151，左上角登记在角色画布的 (64, 137)。49 格分别登记肩、肘、腕及指尖，把两条手臂逐帧画回无臂底稿。双手落到裙侧后，`turn-settle.webp` 用转身段从第 11 帧到第 0 帧的上半身画稿反向衔接到同一个站姿。该图集 3 行 × 4 列，每格 384 × 360。

`release.webp` 每格记录从身前合拢至裙侧放低的一帧，返程到桌边时逆序使用。腿部关节、重心与衣摆缓动均按 60 Hz 单独计算。原始角色署名和改编许可见[壁纸素材说明](../../../../public/themes/character-backgrounds/NOTICE.md)。
