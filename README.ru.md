# piGUI — информация на русском

piGUI is an independent desktop GUI for the Pi coding agent. The current canonical project
documentation is the Chinese-first [README.md](README.md). An up-to-date Russian translation is
not available yet.

piGUI evolved from `agegr/pi-web`, but it has its own repository and release process. Do not use
the former `@agegr/pi-web` installation commands for piGUI.
